# Mana and Artifice Forgotten Cantrips

This project is an add-on for the Minecraft Mana And Artifice mod, adding many new cantrips, such as Lightning, Spectral Bed and Force Consume.

This project is licensed under the terms of the MIT [license](/LICENSE).

[Historical](/reports/week2/user-stories.md) and [current](/docs/user-stories.md) user-stories documents. The scope hasn't significantly changed since week 2, with us still planning to add around ten new cantrips. [Customer feedback](/reports/week2/analysis.md#validated-assumptions) was received during week 2, but wasn't related to cantrips planned for this sprint. Next week we plan to implement 3-5 more cantrips from our backlog.

This week we've decided to attempt to implement the following cantrips: [Spectral Bed (US-003)](https://github.com/Ultrad00d/MnA_Extra_Cantrips/issues/22), [Lightning (US-004)](https://github.com/Ultrad00d/MnA_Extra_Cantrips/issues/23), [Spectral Boat (US-006)](https://github.com/Ultrad00d/MnA_Extra_Cantrips/issues/25)
